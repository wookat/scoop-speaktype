# scoop-speaktype

Scoop bucket for [SpeakType](https://github.com/wookat/speaktype) — open-source hold-to-talk AI voice typing for Windows, offline by default.

## Install

```powershell
scoop bucket add speaktype https://github.com/wookat/scoop-speaktype
scoop install speaktype
```

## What is SpeakType?

Hold a hotkey, speak, release — the recognized, punctuated text lands at your cursor in any app. Local ASR (SenseVoice / Parakeet / whisper.cpp) by default, optional BYOK cloud providers.

Website: https://speaktype.zalize.com
